# Build roadmap

## Phase 1 — Included in this package

- Full Binance Spot USDT universe snapshot
- Fast liquidity/movement filtering
- Multi-timeframe deep scan
- Six setup detectors
- Structure/ATR-based entry and stop calculation
- Deterministic variable reward multiples
- Natural account-specific captions with `$COIN`
- Phrase memory
- Six-account routing
- Five unique symbols per account per hourly batch
- Dry-run API and JSON preview
- Remote Appium screenshot worker skeleton
- Adapter for Binance's official Square posting scripts

## Phase 2 — Needs your cloud credentials and one real device

- Calibrate Binance mobile navigation and crop
- Validate chart symbol/timeframe without OCR
- Add screenshot queue and retries
- Add private object storage

## Phase 3 — Needs one authorized Square test key

- Test one image post
- Record returned post ID/link
- Enforce per-account daily and hourly counters
- Add backoff for platform restriction/error codes

## Phase 4 — Multi-account production

- Add all authorized creator keys in a cloud secrets manager
- Enable staggered slots
- Keep global symbol uniqueness
- Add dashboard authentication and emergency pause
- Add outcome tracking for truthful follow-up captions

## Honest quota behavior

The router reserves five unique symbols per account when the candidate pool is large enough. It reports shortages instead of fabricating a setup. Scanning more symbols and multiple timeframes increases coverage, but no responsible signal engine can guarantee thirty genuinely valid opportunities in every market hour.
